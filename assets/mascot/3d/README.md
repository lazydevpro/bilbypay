# Bilby mascot: 3D runtime assets

| File | Use |
|---|---|
| `bilby.glb` | Full detail (4K body texture). For renders, marketing and desktop web |
| `bilby_lite.glb` | Decimated. For mobile / in-app |

Both are skinned; the rest pose is a **T-pose**. Clips: `Idle` (loop), `Hello` (4.5 s), `Run` (0.33 s loop), `Hop`, `TailWag` (loop), `Blink`.
They're generated by [`../blender/export_glb.py`](../blender/export_glb.py) from the Blender source in [`../blender/`](../blender/).

```bash
node serve.mjs 5173     # viewer at http://localhost:5173
                        #   ?clip=Hello  autoplay a clip
                        #   ?model=bilby_lite.glb
                        #   ?toon=0      plain PBR instead of cel shading
```

## Matching the 2D look at runtime (three.js / R3F)

Swap each material for `MeshToonMaterial` with a two-step gradient, keeping `map` and `color`. Use
`AmbientLight(0xffffff, 2.12)` and `DirectionalLight(0xffffff, 1.1)`. With those, the lit colours land
within a few RGB levels of the reference palette. See `index.html`.

## Animating

- Play the baked clips with `AnimationMixer`, or drive bones directly: `scene.getObjectByName('head')`, `ear_L.2`, `tail.3`, `pupil_L`…
- Blink: squash `eye_L` / `eye_R` (the `Blink` clip does this).
- Happy face: slide `eyehappy_L/R` + `mouth_open` out and `eye_L/R` + `mouth` in (see `Hello`).
- Look around: rotate `pupil_L` / `pupil_R`.
- For new clips, open `../blender/bilby.blend`, add an Action on `BilbyRig`, and re-run `export_glb.py`.
